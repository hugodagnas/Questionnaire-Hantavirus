# Questionnaire Hantavirus

Questionnaire web simple destine a guider le recueil d'informations lors d'un appel pour "Malade" ou "Malaise", a la creation du DRM, avec une anteriorite de 6 semaines.

## Acces

[Ouvrir le questionnaire](https://hugodagnas.github.io/Questionnaire-Hantavirus/)

## Fonctionnalites

- Questionnaire en 4 questions avec reponses Oui/Non.
- Alerte "Orientation AMU obligatoire" si au moins une reponse est positive.
- Bouton de copie du compte rendu au format DRM.
- Mise en evidence des questions non renseignees avant la copie.
- Mode sombre par defaut avec interrupteur clair/sombre.
- Aide contextuelle sur les zones geographiques a risque.
- Interface responsive pour ordinateur et mobile.

## Utilisation

1. Ouvrir le questionnaire.
2. Repondre aux 4 questions.
3. Utiliser les aides geographiques de la question 1 si besoin.
4. Cliquer sur "Copier dans le DRM".
5. Coller le texte copie dans le DRM.

## Deploiement

Le site est un fichier statique `index.html`, publie via GitHub Pages depuis la branche `main`.
